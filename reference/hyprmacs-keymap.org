#+title: Hyprmacs Keymap
#+property: header-args:lua :tangle hyprmacs-keymap.lua

* Purpose

Hyprmacs provides Emacs-like key chords on top of Hyprland's Lua submaps.

Hyprland submaps are modal by default. A submap stays active until something
explicitly leaves it, and a =catchall= only resets after an unmatched keypress.
This file uses submaps as temporary prefix maps instead: a prefix enters a
generated submap, a final command runs, and the helper immediately returns to
the normal =reset= submap.

Examples:

#+begin_src lua :tangle no
keymap_exec("s-x space", "$(tofi-run)")
keymap_exec("s-x e e", "emacsclient -c")
keymap_set("s-f s-f", hl.dsp.window.fullscreen({ mode = "maximized", action = "toggle" }))
keymap_set("s-x s-c", hl.dsp.window.close())
#+end_src

The final command always hard-resets. That is what keeps commands like
=tofi-run= from opening while Hyprland is still listening in the =s-x= submap.

* Public API

- =keymap_set(sequence, dispatcher, flags)= registers a dispatcher action.
- =keymap_exec(sequence, cmd, flags)= registers an =exec= command.
- =keymap_configure(config)= changes helper-level settings.
- =bind(keys, dispatcher, flags)= wraps a normal final bind with the same
  hard-reset behavior used by keymap leaves.
- =bind_exec(keys, cmd, flags)= registers an =exec= command through =bind=.
- =bind_submap(keys, name, flags)= enters a submap as a prefix.
- =enter_submap(name)= enters a submap immediately.
- =reset_submap()= returns to Hyprland's normal =reset= submap.

The helper intentionally keeps these functions global because the rest of this
Hyprland config calls them directly from separate Lua modules.

* Key Syntax

Key sequences are strings with space-separated chords:

#+begin_src lua :tangle no
keymap_exec("s-x e c", "code")
#+end_src

The Emacs-style modifier parser is case-sensitive:

- =s-= means Super.
- =C-= means Control.
- =M-= means Meta/Alt.
- =S-= means Shift.

Modifiers must appear before the final key. The final key is never interpreted
as a modifier token, so these mean different things:

- =s-c= means =SUPER + C=.
- =C-c= means =CTRL + C=.
- =s= by itself means the normal =s= key.
- =c= by itself means the normal =c= key.

Multiple modifiers are canonicalized as =C M s S= before being passed to
Hyprland. For example, =s-M-C-c= becomes =CTRL + ALT + SUPER + C=.

Single letter final keys are normalized to uppercase for Hyprland. These aliases
are also recognized:

- =SPC= or =SPACE= -> =space=
- =RET= or =RETURN= -> =return=
- =ESC= or =ESCAPE= -> =escape=

Any chord containing =+= is treated as raw Hyprland syntax and passed through:

#+begin_src lua :tangle no
keymap_set("SUPER + F", hl.dsp.window.fullscreen())
#+end_src

Held modifiers are not carried into later chords. If the later chord should
require Super, write it explicitly:

#+begin_src lua :tangle no
keymap_exec("s-x space", "$(tofi-run)")
keymap_exec("s-x s-space", "$(tofi-run)")
#+end_src

Those are different bindings.

* Duplicate Final Bindings

Hyprland can register multiple commands on the same key in a row. Hyprmacs does
the same by default for duplicate final commands:

#+begin_src lua :tangle no
keymap_set("s-x f", action1)
keymap_set("s-x f", action2)
#+end_src

That is allowed silently by default.

To restore strict duplicate rejection:

#+begin_src lua :tangle no
keymap_configure({ strict_duplicates = true })
#+end_src

To keep duplicates allowed but report them through Hyprland's internal
notification system:

#+begin_src lua :tangle no
keymap_configure({ report_duplicates = true })
#+end_src

If =strict_duplicates= and =report_duplicates= are both true, strict mode wins.

Prefix/final conflicts are always errors:

#+begin_src lua :tangle no
keymap_set("s-x", action)
keymap_set("s-x f", action)
#+end_src

and:

#+begin_src lua :tangle no
keymap_set("s-x f", action)
keymap_set("s-x", action)
#+end_src

Both are invalid because a key sequence cannot be both a prefix and a final
command.

* Runtime Model

Hyprmacs builds a prefix tree. Prefix nodes get deterministic submap names based
on their parsed path.

For example:

#+begin_src lua :tangle no
keymap_exec("s-x e e", "emacsclient -c")
#+end_src

creates this logical tree:

#+begin_example
root
  SUPER + X -> submap keymap_SUPER_X
    E -> submap keymap_SUPER_X__E
      E -> exec emacsclient -c
#+end_example

Prefix binds call =bind_submap()=. Leaf binds call =bind_keymap_leaf()=.
Hyprland can report overlapping same-key modifier chords while modifiers are
being released. Hyprmacs therefore commits modified leaf chords after a short
settling window and keeps the strongest same-key chord seen during that window.
That keeps overlapping chords such as =M-print= and =s-M-print= resolved by the
final key chord instead of by whichever modifier is released first afterwards.

=bind_submap()=:

1. Records the entering key's same-event leaf callbacks as temporarily
   suppressed.
2. Resets to Hyprland's normal =reset= submap.
3. Enters the child keymap submap.
4. Starts the optional timeout if =submap_timeout_ms= is configured.

=bind()=:

1. Ignores one suppressed same-key event if present.
2. Fully resets the submap.
3. Dispatches the final action.
4. Fully resets again.

The same-key suppression is needed because Lua binds are registered under
Hyprland's Lua handler. Dispatching =hl.dsp.submap(...)= from Lua does not stop
Hyprland from continuing the current key event scan the way a native =submap=
handler does. Without the suppression guard, =s-f s-f= can collapse into a
single =s-f= press.

* Reset Binds

Each generated prefix submap gets =escape= and =catchall= reset binds.

Hyprland processes binds in registration order, so =catchall= must be registered
after real leaf and prefix binds. Otherwise it can consume plain leaves before
they run.

Hyprmacs keeps reset binds last by disabling the old reset bind objects and
re-adding fresh =escape= and =catchall= binds after each real bind registration.
It deliberately uses =bind:set_enabled(false)= instead of =Keybind:remove()=,
because remove-by-key is too broad for generated submaps.

* Optional Timeout

Prefix timeout reset is off by default:

#+begin_src lua :tangle no
keymap_configure({ submap_timeout_ms = 5000 })
#+end_src

Timeouts are generation-guarded, so an old timer cannot reset a newer chord
sequence.

* Implementation

#+begin_src lua
-- -*- mode: lua; -*-

function reset_submap()
    return hl.dispatch(hl.dsp.submap("reset"))
end

local suppressed_leaf_presses = {}
local pending_leaf_actions = {}
local keymap_root = { children = {}, path = {}, submap = nil, reset_binds = {} }
local keymap_config = {
    submap_timeout_ms = nil,
    modified_leaf_commit_delay_ms = 750,
    strict_duplicates = false,
    report_duplicates = false,
}
local keymap_submap_generation = 0

local function key_id(keys)
    return string.lower((keys:gsub("%s+", "")))
end

local function copy_flags(flags)
    local copied = {}
    for key, value in pairs(flags or {}) do
        copied[key] = value
    end
    return copied
end

local function dispatch_action(dispatcher)
    if type(dispatcher) == "function" then
        return dispatcher()
    end
    return hl.dispatch(dispatcher)
end

local function bind_raw(keys, callback, flags)
    return hl.bind(keys, callback, flags or {})
end

local function full_reset()
    keymap_submap_generation = keymap_submap_generation + 1
    reset_submap()
end

local function keymap_report(text, icon)
    if keymap_config.report_duplicates and hl.notification ~= nil then
        hl.notification.create({
            text = text,
            duration = 5000,
            icon = icon or "info",
        })
    end
end

function bind(keys, dispatcher, flags)
    local id = key_id(keys)
    bind_raw(keys, function()
        local suppressed_count = suppressed_leaf_presses[id] or 0
        if suppressed_count > 0 then
            suppressed_leaf_presses[id] = suppressed_count - 1
            if suppressed_leaf_presses[id] == 0 then
                suppressed_leaf_presses[id] = nil
            end
            return
        end
        full_reset()
        local result = dispatch_action(dispatcher)
        full_reset()
        return result
    end, flags or {})
end

local function split_chord(chord)
    local parts = {}
    for part in chord:gmatch("[^+]+") do
        local trimmed = part:gsub("^%s+", ""):gsub("%s+$", "")
        table.insert(parts, trimmed)
    end
    return parts
end

local function chord_signature(chord)
    local parts = split_chord(chord)
    local modifiers = {}
    for index = 1, #parts - 1 do
        modifiers[parts[index]] = true
    end
    return {
        key = key_id(parts[#parts] or chord),
        modifiers = modifiers,
    }
end

local function modifier_count(modifiers)
    local count = 0
    for _ in pairs(modifiers or {}) do
        count = count + 1
    end
    return count
end

local function modifiers_contain_all(superset, subset)
    for modifier in pairs(subset or {}) do
        if superset[modifier] == nil then
            return false
        end
    end
    return true
end

local function dispatch_leaf_action(dispatcher)
    full_reset()
    local result = dispatch_action(dispatcher)
    full_reset()
    return result
end

local function stronger_signature(candidate, current)
    if current == nil then
        return true
    end

    local candidate_count = modifier_count(candidate.modifiers)
    local current_count = modifier_count(current.modifiers)
    return candidate_count > current_count
        and modifiers_contain_all(candidate.modifiers, current.modifiers)
end

local function weaker_signature(candidate, current)
    if current == nil then
        return false
    end

    local candidate_count = modifier_count(candidate.modifiers)
    local current_count = modifier_count(current.modifiers)
    return current_count > candidate_count
        and modifiers_contain_all(current.modifiers, candidate.modifiers)
end

local function queue_leaf_action(signature, dispatcher)
    if modifier_count(signature.modifiers) == 0 or keymap_config.modified_leaf_commit_delay_ms == nil then
        return dispatch_leaf_action(dispatcher)
    end

    local pending = pending_leaf_actions[signature.key]
    if weaker_signature(signature, pending and pending.signature) then
        return
    end

    if pending == nil or stronger_signature(signature, pending.signature) or not weaker_signature(signature, pending.signature) then
        pending = {
            generation = (pending and pending.generation or 0) + 1,
            signature = signature,
            dispatcher = dispatcher,
        }
        pending_leaf_actions[signature.key] = pending
    else
        pending.generation = pending.generation + 1
    end

    local generation = pending.generation
    local key = signature.key
    hl.timer(function()
        local latest = pending_leaf_actions[key]
        if latest == nil or latest.generation ~= generation then
            return
        end
        pending_leaf_actions[key] = nil
        dispatch_leaf_action(latest.dispatcher)
    end, { timeout = keymap_config.modified_leaf_commit_delay_ms, type = "oneshot" })
end

local function bind_keymap_leaf(keys, dispatcher, flags)
    local id = key_id(keys)
    local signature = chord_signature(keys)
    bind_raw(keys, function()
        local suppressed_count = suppressed_leaf_presses[id] or 0
        if suppressed_count > 0 then
            suppressed_leaf_presses[id] = suppressed_count - 1
            if suppressed_leaf_presses[id] == 0 then
                suppressed_leaf_presses[id] = nil
            end
            return
        end
        return queue_leaf_action(signature, dispatcher)
    end, flags or {})
end

function enter_submap(name)
    return hl.dispatch(hl.dsp.submap(name))
end

function bind_submap(keys, name, flags, suppress_count)
    local bind_flags = copy_flags(flags)

    bind_raw(keys, function()
        local id = key_id(keys)
        if type(suppress_count) == "function" then
            suppressed_leaf_presses[id] = suppress_count()
        else
            suppressed_leaf_presses[id] = suppress_count or 1
        end

        reset_submap()
        keymap_submap_generation = keymap_submap_generation + 1
        local timeout_generation = keymap_submap_generation
        local result = enter_submap(name)
        if keymap_config.submap_timeout_ms ~= nil then
            hl.timer(function()
                if keymap_submap_generation == timeout_generation then
                    full_reset()
                end
            end, { timeout = keymap_config.submap_timeout_ms, type = "oneshot" })
        end
        return result
    end, bind_flags)
end

function keymap_configure(config)
    for key, value in pairs(config or {}) do
        keymap_config[key] = value
    end
end

local function normalize_key_name(key)
    local aliases = {
        [" "] = "space",
        ["RET"] = "return",
        ["RETURN"] = "return",
        ["ESC"] = "escape",
        ["ESCAPE"] = "escape",
        ["SPC"] = "space",
        ["SPACE"] = "space",
    }
    local upper = string.upper(key)
    if aliases[upper] then
        return aliases[upper]
    end
    if #key == 1 and key:match("%a") then
        return upper
    end
    return key
end

local function parse_emacs_modifier(modifier)
    if modifier == "s" then
        return "SUPER"
    elseif modifier == "C" then
        return "CTRL"
    elseif modifier == "M" then
        return "ALT"
    elseif modifier == "S" then
        return "SHIFT"
    end
    return nil
end

local function parse_emacs_chord(chord)
    if chord:find("%+") then
        return chord
    end

    local parts = {}
    for part in chord:gmatch("[^-]+") do
        table.insert(parts, part)
    end

    if #parts == 0 then
        error("keymap_set: invalid chord " .. chord)
    end
    if #parts == 1 then
        return normalize_key_name(parts[1])
    end

    local seen_mods = {}
    for index = 1, #parts - 1 do
        local parsed = parse_emacs_modifier(parts[index])
        if parsed == nil then
            return chord
        end
        seen_mods[parts[index]] = parsed
    end

    local mods = {}
    for _, modifier in ipairs({ "C", "M", "s", "S" }) do
        if seen_mods[modifier] ~= nil then
            table.insert(mods, seen_mods[modifier])
        end
    end
    table.insert(mods, normalize_key_name(parts[#parts]))
    return table.concat(mods, " + ")
end

local function parse_key_sequence(sequence)
    if type(sequence) == "table" then
        local chords = {}
        for _, chord in ipairs(sequence) do
            table.insert(chords, parse_emacs_chord(chord))
        end
        return chords
    end

    local chords = {}
    for chord in sequence:gmatch("%S+") do
        table.insert(chords, parse_emacs_chord(chord))
    end
    return chords
end

local function submap_name(path)
    local name = table.concat(path, "__")
    name = name:gsub("[^%w]+", "_"):gsub("^_+", ""):gsub("_+$", "")
    return "keymap_" .. name
end

local function in_submap(node, callback)
    if node.submap == nil then
        callback()
    else
        hl.define_submap(node.submap, callback)
    end
end

local function disable_binds(binds)
    for _, bind in ipairs(binds or {}) do
        bind:set_enabled(false)
    end
end

local function refresh_reset_binds(node)
    if node.submap == nil then
        return
    end

    disable_binds(node.reset_binds)
    node.reset_binds = {}

    hl.define_submap(node.submap, function()
        table.insert(node.reset_binds, bind_raw("escape", function()
            full_reset()
        end))
        table.insert(node.reset_binds, bind_raw("catchall", function()
            full_reset()
        end))
    end)
end

local function same_key_action_count(node, chord)
    local child = node.children[chord]
    if child ~= nil and child.actions ~= nil and #child.actions > 0 then
        return #child.actions
    end
    return 1
end

local function ensure_prefix(parent, chord)
    local child = parent.children[chord]
    if child ~= nil then
        return child
    end

    local path = {}
    for _, item in ipairs(parent.path) do
        table.insert(path, item)
    end
    table.insert(path, chord)

    child = {
        children = {},
        path = path,
        submap = submap_name(path),
        reset_binds = {},
    }
    parent.children[chord] = child

    in_submap(parent, function()
        bind_submap(chord, child.submap, nil, function()
            return same_key_action_count(child, chord)
        end)
    end)
    refresh_reset_binds(parent)

    return child
end

function keymap_set(sequence, dispatcher, flags)
    local chords = parse_key_sequence(sequence)
    if #chords == 0 then
        error("keymap_set: empty key sequence")
    end

    local node = keymap_root
    for index, chord in ipairs(chords) do
        if index < #chords then
            local child = node.children[chord]
            if child ~= nil and child.actions ~= nil and #child.actions > 0 then
                error("keymap_set: " .. table.concat(chords, " ") .. " conflicts with final binding " .. table.concat(child.path, " "))
            end
            node = ensure_prefix(node, chord)
        else
            local existing = node.children[chord]
            if existing ~= nil and next(existing.children) ~= nil then
                error("keymap_set: " .. table.concat(chords, " ") .. " conflicts with prefix binding " .. table.concat(existing.path, " "))
            end
            if existing ~= nil and existing.actions ~= nil and #existing.actions > 0 then
                if keymap_config.strict_duplicates then
                    error("keymap_set: duplicate binding " .. table.concat(chords, " "))
                end
                keymap_report("Hyprmacs duplicate final binding: " .. table.concat(chords, " "), "info")
            end

            local path = {}
            for _, item in ipairs(node.path) do
                table.insert(path, item)
            end
            table.insert(path, chord)

            local leaf = existing or {
                children = {},
                path = path,
                submap = nil,
                reset_binds = {},
                actions = {},
            }
            leaf.path = path
            leaf.actions = leaf.actions or {}
            table.insert(leaf.actions, dispatcher)
            node.children[chord] = leaf

            in_submap(node, function()
                bind_keymap_leaf(chord, dispatcher, flags)
            end)
            refresh_reset_binds(node)
        end
    end
end

function keymap_exec(sequence, cmd, flags)
    local bind_flags = flags or {}
    local rules = bind_flags.rules
    if rules ~= nil then
        bind_flags = {}
        for key, value in pairs(flags) do
            if key ~= "rules" then
                bind_flags[key] = value
            end
        end
    end
    keymap_set(sequence, hl.dsp.exec_cmd(cmd, rules), bind_flags)
end

function bind_exec(keys, cmd, flags)
    local bind_flags = flags or {}
    local rules = bind_flags.rules
    if rules ~= nil then
        bind_flags = {}
        for key, value in pairs(flags) do
            if key ~= "rules" then
                bind_flags[key] = value
            end
        end
    end
    bind(keys, hl.dsp.exec_cmd(cmd, rules), bind_flags)
end
